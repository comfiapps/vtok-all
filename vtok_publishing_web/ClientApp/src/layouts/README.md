# 📂 ClientApp/src/layouts - 메인 페이지 레이아웃 명세

VTOK 랜딩페이지의 구획별 레이아웃 섹션 디렉토리입니다.

---

## 📄 파일 명세

- **`Main/Home.js`**: 메인 랜딩 히어로 섹션 (타이틀 캐치프레이즈 & 민팅 참여 딥링크 CTA).
- **`NFT/index.js`**: VTOK NFT 수집품 카드 갤러리 섹션.
- **`Roadmap/index.js`**: 타임라인 형태의 4단계 로드맵 카드 섹션.
- **`Service/`**:
  - `ServiceTabs.js`: 탭 제어 모듈 (`Pet`, `Story`, `Feature`).
  - `Pet.js`: Animated WebP 캐릭터 펫 인터랙션 섹션.
  - `Story.js`: VTOK 메타버스 브랜드 스토리텔링 섹션.
- **`Team/index.js`**: 14명 팀원의 프로필 그래픽 이미지 및 연관 역할 소개 카드 그리드.
- **`Partner/index.js`**: 공식 파트너사 브랜드 로고 카러셀.
