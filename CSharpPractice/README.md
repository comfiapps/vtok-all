# 📘 CSharpPractice (C# 알고리즘 및 문법 연습)

C# 10 및 .NET 6 환경에서 그래픽 알고리즘(BFS, DFS), OOP 클래스 설계 및 자료구조 실습을 위한 콘솔 프로젝트입니다.

---

## 📂 디렉토리 구조 (Directory Structure)

```text
CSharpPractice/
└── CSharpPractice/        # C# 소스 파일 디렉토리
    ├── BFS.cs             # Queue 기반 너비 우선 탐색 (Breadth-First Search)
    ├── DFS.cs             # Recursion/Stack 기반 깊이 우선 탐색 (Depth-First Search)
    ├── AlgorithmPractice.cs # 그리디, DP 및 정렬 알고리즘 실습
    └── Program.cs         # 콘솔 애플리케이션 진입점 (Main)
```
