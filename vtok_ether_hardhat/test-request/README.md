# 📡 Test Request - 외부 블록체인 탐색기 REST API 테스트

VS Code REST Client 또는 IntelliJ HTTP Client를 통해 외부 블록체인 익스플로러 API와 통신하기 위한 `.http` 요청 스크립트 모음입니다.

* **`etherscan-api.http`**: Etherscan API를 통한 주소별 잔액, 트랜잭션 히스토리, 가스 오라클 조회.
* **`ethplorer-api.http`**: Ethplorer API를 통한 토큰 홀더 목록 및 주소별 토큰 인벤토리 수집.
* **`solarbot.http`**: 봇 자동화 및 가스비 모니터링 웹훅 요청.
