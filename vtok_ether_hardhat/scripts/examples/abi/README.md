# 📋 ABI (Application Binary Interface) 디렉토리

스마트 컨트랙트와 프론트엔드/백엔드 간 상호작용에 필수적인 함수 시그니처 및 이벤트 정의 JSON 인터페이스 명세입니다.

* **`erc721-abi.json`**: ERC-721 표준 인터페이스 (`ownerOf`, `transferFrom`, `approve`, `balanceOf`).
* **`erc721metadata-abi.json`**: 메타데이터 확장 규격 (`name`, `symbol`, `tokenURI`).
* **`opensea-abi.json`**: OpenSea 마켓플레이스 프록시 레지스트리 및 컨트랙트 상호작용 규격.
