# 🏠 Layouts Main - 메인 히어로 뷰 레이아웃

웹사이트 진입 시 가장 먼저 노출되는 첫 화면 레이아웃으로, `Home.js` 및 섹션 스크롤러와 통합되어 있습니다.

* **`Home.js`**:
  * 배경 일러스트, 캐치프레이즈 문구, 3D 하우스 프리뷰(`HousePreview`), 민팅 박스(`MintBox`), 카운트다운 타이머(`CountDownTimer`)를 유기적으로 배치.
  * 백엔드 API 상태에 따라 민팅 진행 상태(`mode`) 전환.
* **`index.js`**:
  * 메인 앱바, 스크롤러 및 전체 6대 메인 섹션을 순차적으로 렌더링하는 컨테이너.
