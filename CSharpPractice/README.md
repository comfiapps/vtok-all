# 📘 CSharpPractice (C# 알고리즘 및 문법 연습)

C# 10 및 .NET 6 환경에서 그래프 알고리즘, 객체지향 기초 및 데이터 구조를 테스트하는 연습 프로젝트입니다.

---

## 📂 디렉토리 구조 (Directory Structure)

```text
CSharpPractice/
└── CSharpPractice/        # C# 연습 콘솔/라이브러리 프로젝트
    ├── BFS.cs             # 너비 우선 탐색(Breadth-First Search) 알고리즘
    ├── DFS.cs             # 깊이 우선 탐색(Depth-First Search) 알고리즘
    ├── AlgorithmPractice.cs # 알고리즘 종합 실습
    └── Program.cs         # 메인 진입점
```
