# 🐍 python_rest_api_practice (Python Flask REST API 예제)

Python Flask 및 Requests 라이브러리를 활용한 RESTful API 엔드포인트 구축 및 Producer/Consumer 메시징 데이터 처리 예제입니다.

---

## 🛠️ 주요 소스 파일 (Key Files)

- **`main.py`**: Flask 기반 REST API 개발 서버 실행 예제.
- **`produce.py`**: 데이터 생산자(Producer) HTTP POST 요청 발송 스크립트.
- **`consume.py`**: 데이터 소비자(Consumer) 엔드포인트 수신 및 파싱 스크립트.

---

## 🚀 실행 방법 (Execution)

```bash
python main.py
```
