# 🛠️ Layouts Service - 4대 메타버스 서비스 탭 레이아웃

iSOBOX 플랫폼의 핵심 4대 서비스(**Trade, Creation, Housing, Community**)를 스와이퍼(Swiper) 슬라이더와 탭 전환 인터페이스로 소개하는 레이아웃입니다.

* **`ServiceTabs.js`**: 4대 서비스 선택 버튼 및 탭 전환 상태 관리.
* **`AbsoluteBox.js`**: 각 서비스별 기능 설명 카드와 대표 그래픽 배치.
* **`Pet.js`**: 가상 반려동물(Pet) 시스템 및 데코레이션 아이템 소개.
* **`Story.js`**: 메타버스 세계관 스토리 텍스트 슬라이드.
