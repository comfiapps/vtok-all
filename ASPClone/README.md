# 💻 ASPClone (ASP.NET Core Web API 연습)

ASP.NET Core Web API의 Controller-Service-Model 계층화 아키텍처 및 RESTful API 엔드포인트 구현을 실습하기 위한 기초 프로젝트입니다.

---

## 📂 디렉토리 구조 (Directory Structure)

```text
ASPClone/
└── ASPPractice/           # ASP.NET Core Web API 프로젝트
    ├── Controllers/       # DepartmentController, EmployeeController, PizzaController, WeatherForecastController
    ├── Models/            # Department, Employee, Pizza, WeatherForecast 엔티티
    └── Services/          # PizzaService (In-Memory Data Provider)
```
