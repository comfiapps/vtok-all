# 💻 ASPClone (ASP.NET Core Web API 연습)

ASP.NET Core Web API 기본 패턴(Controller-Service-Model)을 실습하기 위한 예제 프로젝트입니다.

---

## 📂 디렉토리 구조 (Directory Structure)

```text
ASPClone/
└── ASPPractice/           # Web API 프로젝트
    ├── Controllers/       # DepartmentController, EmployeeController, PizzaController
    ├── Models/            # Department, Employee, Pizza 데이터 모델
    └── Services/          # PizzaService
```
