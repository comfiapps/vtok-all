# ⏱️ CountDownTimer - 라운드 카운트다운 타이머 컴포넌트

민팅 라운드 시작 전 사용자에게 오픈 일시까지 남은 시간(일, 시, 분, 초)을 대형 애니메이션 카드로 시각화하는 컴포넌트입니다.

* **동작 원리**:
  * 백엔드 `/api/time`에서 수신한 `targetTime`(Unix Epoch Timestamp)과 현재 시각의 차이를 1초(`1000ms`) 인터벌로 계산.
  * 시간이 0에 도달할 경우 `toggle()` 콜백을 호출하여 `Home` 컴포넌트의 화면 모드를 `MintBox`로 자동 전환.
